# Models  UI


The Models UI in Kubeflow is a web application that allows users to manage and monitor their machine learning models. The UI provides a user-friendly interface for creating, deploying, and serving models. It also provides a variety of tools for monitoring model performance and health.

The Models UI is built on top of the KServe framework, which is a Kubernetes-based serving framework for machine learning models. KServe provides a variety of features for serving models, including:

* Automatic model discovery and registration
* Model versioning and management
* Load balancing and autoscaling
* Health monitoring and alerting
